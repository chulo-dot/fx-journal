How it works

Your data

Everything stays in this browser. Nothing is uploaded. Clearing site data removes the journal, so export a CSV now and then as a backup.

Keyboard

  • N add a trade   / search trades   1–5 switch section
  • 1 Dashboard   2 Trades   3 Calculator   4 Analytics   5 Summary
  • Ctrl/? + Enter saves the trade form

How numbers are worked out

  • Return = P&L ÷ account size at entry. Every trade gets one.
  • Total return adds trade returns. Compounded multiplies each day's return.
  • Win rate = winning trades ÷ all trades. Break-even trades count as neither win nor loss.
  • Payoff ratio = average winning return ÷ average losing return.
  • Profit factor = gross profit ÷ gross loss. Expectancy = average P&L per trade.
  • Max drawdown = biggest fall from a balance peak, using starting balance plus P&L.
  • Sharpe = average daily return ÷ its standard deviation × vperiods per year (change in Settings).

Import format

CSV with a header row containing Date, Side (Long or Short) and PnL. Optional: Account Size, Pair, Asset Type (Forex or Crypto), Time Frame, Lots, Entry, Exit, Stop, Risk, Screenshot Before, Screenshot After, Strategy, Notes. Dates read as YYYY-MM-DD, M/D/YYYY or D.M.YYYY. Semicolon files with decimal commas work too.
